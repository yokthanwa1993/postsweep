# PostSweep

**ล้างโพสต์ Facebook จากไอคอนเดียว พร้อมปรับความเร็วได้**

ส่วนขยาย Google Chrome สำหรับย้ายโพสต์ทั้งหมดในหน้า **บันทึกกิจกรรม → โพสต์ → โพสต์ รูปภาพ และวิดีโอของคุณ** ไปถังขยะ ใช้ได้ไม่จำกัดครั้ง ไม่มีค่าสมาชิก

## วิธีใช้

1. กดไอคอน **ถังขยะสีขาวบนพื้นแดง** บนแถบ Chrome จากหน้าไหนก็ได้
2. ส่วนขยายจะเปิด [บันทึกกิจกรรมที่คุณระบุ](https://www.facebook.com/100050886815386/allactivity?activity_history=false&category_key=MANAGEPOSTSPHOTOSANDVIDEOS&manage_mode=false&should_load_landing_page=false) ในแท็บนั้น
3. เมื่อหน้าโหลดเสร็จ ส่วนขยาย **เริ่มลบทันที** ไม่ต้องกดซ้ำหรือยืนยันอีกครั้ง

หน้าต่างกลางจอใช้โทนขาว–น้ำเงิน มีแอนิเมชันสถานะ จำนวนที่ย้ายสำเร็จ และเวลาที่ใช้ กด **หยุดลบโพสต์** ได้ทุกเมื่อ หรือกด **ย่อหน้าต่าง** เพื่อแสดงสถานะขนาดเล็กที่มุมจอ คำสั่งที่ส่งออกไปแล้วไม่เกิน 3 รายการอาจเสร็จหลังจากกดหยุด เปิดแท็บไว้จนเสร็จ แล้วรีเฟรช Facebook เพื่อดูผลล่าสุด

เลื่อนแถบ **ความเร็วในการลบ** ได้ระหว่างทำงาน ส่วนขยายจำค่าที่เลือกไว้ในเครื่อง ความเร็วมี 5 ระดับ:

| ระดับ | เว้นระหว่างเริ่มแต่ละโพสต์ | ทำงานพร้อมกันสูงสุด |
| --- | --- | --- |
| 1 · ช้ามาก | 1.5 วินาที | 1 โพสต์ |
| 2 · ช้า | 0.7 วินาที | 1 โพสต์ |
| 3 · ปกติ | 0.35 วินาที | 2 โพสต์ |
| 4 · เร็ว | 0.15 วินาที | 3 โพสต์ |
| 5 · เร็วสุด | ไม่เพิ่มเวลาหน่วง | 3 โพสต์ |

ครั้งแรกเริ่มที่ระดับ 5 ความเร็วจริงขึ้นกับการตอบกลับของ Facebook เมื่อปรับช้าลง คำสั่งที่ส่งไปแล้วจะทำให้เสร็จก่อนใช้จังหวะใหม่

การกดไอคอนซ้ำระหว่างทำงานจะเปิดกล่องสถานะเดิม หลังหยุดหรือทำงานเสร็จ กดไอคอนอีกครั้งเพื่อเริ่มตรวจรายการที่เหลือใหม่

## ติดตั้งเอง

1. แตกไฟล์ ZIP โดยเก็บโฟลเดอร์ `facebook-cleaner` ไว้ในตำแหน่งถาวร
2. เปิด `chrome://extensions`
3. เปิด **Developer mode / โหมดนักพัฒนาซอฟต์แวร์**
4. กด **Load unpacked / โหลดส่วนขยายที่คลายการแพค** แล้วเลือกโฟลเดอร์ `facebook-cleaner` ที่มี `manifest.json`
5. กดรูปจิ๊กซอว์ใน Chrome แล้วปักหมุด **PostSweep — ล้างโพสต์ Facebook**
6. รีเฟรชแท็บ Facebook หนึ่งครั้งก่อนเริ่มใช้

อย่าลบหรือย้ายโฟลเดอร์ที่ติดตั้งอยู่ เพราะ Chrome โหลดส่วนขยายจากโฟลเดอร์นั้นโดยตรง

## ขอบเขตการทำงาน

- ลบต่อเนื่องด้วยความเร็วที่เลือก ย้ายไปถังขยะพร้อมกันสูงสุด 3 โพสต์ และโหลดรายการถัดไปเอง
- จัดการเฉพาะโพสต์ในหมวดนี้ที่ Facebook ส่งตัวเลือก `MOVE_TO_TRASH` มาให้ รายการที่ Facebook ไม่รองรับจะแสดงเป็น “ย้ายไม่ได้”
- ไม่ลบคอมเมนต์ การกดถูกใจ ข้อความแชท หรือเนื้อหาในหมวดอื่น
- ตรวจเจ้าของลิงก์กับบัญชีที่ล็อกอิน รวมถึงกรณีเปิดบันทึกกิจกรรมบัญชีส่วนตัวขณะใช้โปรไฟล์เพจ
- หยุดเมื่อมีข้อผิดพลาดหรือบัญชีเปลี่ยน หากผลของคำสั่งไม่แน่ชัด ให้ตรวจถังขยะใน Facebook ก่อนเริ่มใหม่
- ไม่มีการส่งคำสั่งลบถาวรหรือสั่งล้างถังขยะ โพสต์จะถูกลบตามกำหนด 30 วันของ Facebook และกู้คืนได้ก่อนครบกำหนด ([คำอธิบายจาก Meta](https://about.fb.com/news/2020/06/introducing-manage-activity/))

## ข้อมูลและสิทธิ์

ใช้ Manifest V3 พร้อมสิทธิ์ `activeTab`, `scripting`, `storage` และเข้าถึง `https://www.facebook.com/*` เพื่อเริ่มงานหลังพาแท็บไปบันทึกกิจกรรม เก็บเฉพาะค่าความเร็วในเครื่อง ส่วนขยายเริ่มงานจากการกดไอคอนเท่านั้น การเปิดหรือรีเฟรช Facebook ตามปกติจะไม่เริ่มลบ ไม่มีเซิร์ฟเวอร์ภายนอก ไม่มีระบบติดตาม ไม่มีการเก็บรหัสผ่าน คุกกี้ หรือโทเคนลงไฟล์ ใช้เซสชัน Facebook ปัจจุบันภายในแท็บนั้น คำสั่งทั้งหมดส่งตรงไปยัง Facebook

ซอร์สโค้ดเขียนขึ้นใหม่จากรูปแบบคำขอและคำตอบใน HAR ที่ผู้ใช้ให้ ไม่มีไฟล์ HAR หรือข้อมูลล็อกอินรวมอยู่ในชุดติดตั้ง

## สถานะการทดสอบ

ทดสอบการอ่านคำตอบจริงจาก HAR และทดสอบสถานการณ์ลบต่อเนื่องด้วยโพสต์จำลอง รวมถึงการแบ่งหน้า รายการซ้ำ กดหยุด ข้อผิดพลาด บัญชีไม่ตรง และการเปิดงานซ้อน การนำทางจากไอคอน แถบปรับความเร็ว การจำค่า และการกดหยุดขณะรอ ผู้พัฒนาใช้โพสต์จำลองในการตรวจการอัปเดตนี้

Facebook ใช้คำสั่งภายในที่อาจเปลี่ยนได้ หากโครงสร้างเปลี่ยนหรือเซสชันหมดอายุ ส่วนขยายจะหยุดและแสดงข้อความให้ทราบ ไม่รับประกันความเร็วเท่ากันในทุกบัญชี

เอกสารที่ใช้อ้างอิง: [Chrome activeTab](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab), [Chrome scripting](https://developer.chrome.com/docs/extensions/reference/api/scripting), [การติดตั้งส่วนขยายแบบ unpacked](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world)

## สำหรับพัฒนา

ใช้ Node.js 20 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม

```sh
npm test
```

ทดสอบหน้าต่างและการทำงานต่อเนื่องกับข้อมูลจำลอง:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

จากนั้นเปิด `http://127.0.0.1:8765/tests/runner.html` และ `http://127.0.0.1:8765/tests/speed-runner.html` ใน Chrome ชุดทดสอบใช้โพสต์จำลองและไม่เชื่อมต่อ Facebook

ไฟล์หลัก: `launcher.js` เปิดหน้าที่ตั้งไว้และเริ่มงาน, `controller.js` แสดงหน้าต่างและจัดคิวตามความเร็ว, `facebook.js` ตรวจบัญชีและสื่อสารกับ Facebook

ข้อมูลใน `tests/fixtures` สร้างขึ้นสำหรับทดสอบ ไม่มี HAR คุกกี้ หรือโทเคนจริงใน repository นี้
