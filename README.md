# PostSweep

**ล้างโพสต์ Facebook เลือกวัน เดือน หรือช่วงวันที่จากปฏิทินก่อนเริ่ม**

ส่วนขยาย Chrome สำหรับย้ายโพสต์ไปถังขยะ ใช้กับเพจหรือโปรไฟล์ที่กำลังสลับใช้อยู่บน Facebook ใช้ได้ไม่จำกัดครั้ง ไม่มีค่าสมาชิก

เป็นส่วนขยายอิสระ ไม่ใช่ผลิตภัณฑ์ของ Meta

## วิธีใช้

1. เปิด Facebook แล้วสลับเป็นเพจหรือโปรไฟล์ที่ต้องการจัดการ
2. กดไอคอน **ถังขยะสีขาวบนพื้นแดง** กล่องปฏิทินจะแสดงใต้ไอคอน พร้อมชื่อโปรไฟล์ที่ใช้อยู่
3. เลือก **ทั้งหมด / วันที่ / เดือน / ช่วงวันที่**
4. กด **เริ่มลบ** ส่วนขยายจะเปิดบันทึกกิจกรรมของโปรไฟล์นั้นในแท็บที่ใช้อยู่ แล้วเริ่มทำงาน

การเปิดกล่องส่วนขยาย การเปลี่ยนปฏิทิน และการรีเฟรช Facebook จะไม่เริ่มลบ ต้องกดปุ่มเริ่มลบก่อนเสมอ หากกดจากเว็บอื่น ส่วนขยายจะอ่านโปรไฟล์จากแท็บ Facebook ที่เปิดอยู่ใน Chrome โปรไฟล์เดียวกัน

รองรับแต่ละเพจที่คุณสลับเข้าใช้งานและมีสิทธิ์จัดการโพสต์ ไม่ผูกกับหมายเลขบัญชีใดตายตัว หากสลับโปรไฟล์หลังเปิดกล่อง ให้ปิดแล้วเปิดส่วนขยายใหม่เพื่อตรวจชื่ออีกครั้ง ส่วนขยายตรวจตัวตนซ้ำก่อนเริ่มและก่อนส่งคำสั่งแต่ละรายการ

## ปฏิทินและช่วงเวลา

| ตัวเลือก | วิธีเลือก |
| --- | --- |
| ทั้งหมด | จัดการโพสต์ทุกเดือนและทุกปี |
| วันที่ | คลิกวันบนปฏิทินเพื่อเลือกวันเดียว |
| เดือน | เลือกโหมดเดือน แล้วใช้ลูกศรเลื่อนเดือนหรือปุ่มเปลี่ยนปี |
| ช่วงวันที่ | คลิกวันเริ่มต้นและวันสิ้นสุด เลื่อนข้ามเดือนได้ |

ช่วงวันที่รวมทั้งวันแรกและวันสุดท้าย หากคลิกวันหลังแล้ววันก่อน ส่วนขยายเรียงช่วงให้ตามวันจริง การเลือกวันแรกใหม่จะล้างวันสิ้นสุดและรอให้เลือกครบก่อนเริ่มงาน

ใช้เวลา **Asia/Bangkok (UTC+7)** และปี **ค.ศ.** ทั้งตอนเลือกและแสดงวันที่ โหมดที่จำกัดช่วงเวลาจะข้ามโพสต์ที่ไม่มีวันที่หรืออยู่นอกช่วง ส่วนขยายเก็บช่วงและความเร็วที่เลือกไว้เป็นค่าเริ่มต้นครั้งถัดไป แต่ยังรอให้กดเริ่มลบทุกครั้ง

คลิกขวาไอคอน → **ตัวเลือก / Options** เพื่อตั้งช่วงเริ่มต้นได้ การบันทึกจากหน้าตัวเลือกจะไม่เริ่มลบ

## สถานะการลบ

หน้าต่างกลางจอใช้โทนขาว–น้ำเงินและปรับขนาดให้พอดีหน้าจอ ไม่มีแถบเลื่อนภายใน แสดงจำนวนที่ย้ายสำเร็จ เวลา และวันที่ดังนี้:

- **กำลังลบวันที่**: วันที่ของโพสต์ที่กำลังส่งคำสั่ง หากมีหลายวันพร้อมกันจะแสดงเป็นช่วง ระหว่างค้นหารายการจะแสดง **กำลังตรวจวันที่**
- **ลบสำเร็จล่าสุด**: วันที่ของโพสต์ที่ Facebook เพิ่งยืนยันผลสำเร็จ คำตอบอาจกลับมาไม่ตามลำดับ
- **วันที่เก่าสุดที่ลบสำเร็จในรอบนี้**: วันที่เก่าสุดในรายการที่ย้ายสำเร็จจริง ไม่ได้หมายความว่าทุกโพสต์ที่ใหม่กว่าวันนั้นถูกลบครบแล้ว

กด **หยุดลบโพสต์** ได้ทุกเมื่อ คำสั่งที่ส่งไปแล้วไม่เกิน 3 รายการจะรอผลให้เสร็จ กด **ย่อหน้าต่าง** เพื่อดูสถานะเล็กที่มุมจอ หรือ **เปลี่ยนช่วงเวลา** เพื่อหยุดรอบเดิมก่อนเลือกปฏิทินใหม่ เปิดแท็บไว้จนเสร็จ แล้วรีเฟรช Facebook เพื่อดูผล

## ความเร็ว

ปรับแถบความเร็วระหว่างทำงานได้ ค่าจะใช้กับคำสั่งถัดไป:

| ระดับ | เว้นระหว่างเริ่มแต่ละโพสต์ | พร้อมกันสูงสุด |
| --- | --- | --- |
| 1 · ช้ามาก | 1.5 วินาที | 1 โพสต์ |
| 2 · ช้า | 0.7 วินาที | 1 โพสต์ |
| 3 · ปกติ | 0.35 วินาที | 2 โพสต์ |
| 4 · เร็ว | 0.15 วินาที | 3 โพสต์ |
| 5 · เร็วสุด | ไม่เพิ่มเวลาหน่วง | 3 โพสต์ |

ค่าเริ่มต้นคือระดับ 5 ความเร็วจริงขึ้นกับ Facebook ส่วนการค้นหาช่วงเก่าอาจใช้เวลา เพราะตรวจวันที่ของรายการทีละหน้าจนสุด และไม่ถือว่ารายการเรียงตามวันที่

## ติดตั้งและอัปเดต

1. แตก ZIP หรือดาวน์โหลด repository ไว้ในตำแหน่งถาวร
2. เปิด `chrome://extensions` แล้วเปิด **Developer mode / โหมดนักพัฒนาซอฟต์แวร์**
3. กด **Load unpacked** แล้วเลือกโฟลเดอร์ที่มี `manifest.json`
4. ปักหมุด **PostSweep — ล้างโพสต์ Facebook** จากเมนูจิ๊กซอว์

อย่าย้ายหรือลบโฟลเดอร์ที่ Chrome โหลดอยู่ หลังอัปเดต ให้หยุดรอบปัจจุบันและรอให้เสร็จ กด **Reload / โหลดใหม่** บนการ์ด PostSweep แล้วรีเฟรช Facebook ก่อนเริ่มรอบใหม่

หากกล่องส่วนขยายขึ้น **มีรุ่นใหม่พร้อมใช้งาน** ให้จบรอบที่กำลังลบก่อน แล้วกด **โหลดส่วนขยายใหม่** ในกล่อง เปิดไอคอนอีกครั้งเพื่อตรวจชื่อเพจและเลือกช่วงเวลา การกดโหลดใหม่จะไม่เริ่มลบเอง

Chrome อาจยังใช้ตัวทำงานที่แคชไว้แม้ไฟล์ปฏิทินเปลี่ยนแล้ว รุ่น 1.3.1 ตรวจว่ากล่องกับตัวทำงานใช้รุ่นที่เข้ากันได้ก่อนเปิดปุ่มเริ่ม แก้กรณีที่รุ่นเก่าขึ้น “เริ่มงานจากปุ่มในส่วนขยายเท่านั้น” ทั้งที่เปิดจากไอคอนแล้ว

## ขอบเขตและข้อมูล

จัดการเฉพาะหมวด **โพสต์ รูปภาพ และวิดีโอของคุณ** ที่ Facebook ส่งสิทธิ์ `MOVE_TO_TRASH` กลับมา ไม่ลบข้อความแชท ความคิดเห็น หรือหมวดอื่น ไม่ส่งคำสั่งลบถาวรหรือสั่งล้างถังขยะ โพสต์ในถังขยะกู้คืนได้ก่อนครบ 30 วันตามระบบ [Manage Activity ของ Meta](https://about.fb.com/news/2020/06/introducing-manage-activity/)

ใช้ Manifest V3 พร้อมสิทธิ์ `activeTab`, `scripting`, `storage` และ `https://www.facebook.com/*` เพื่ออ่านโปรไฟล์ เปิดบันทึกกิจกรรม และทำงานในแท็บนั้น เก็บเฉพาะช่วงเวลาและความเร็วในเครื่อง ไม่มีเซิร์ฟเวอร์ภายนอกหรือระบบติดตาม ไม่เก็บรหัสผ่าน คุกกี้ หรือโทเคนลงไฟล์ คำสั่งส่งตรงไปยัง Facebook ด้วยเซสชันปัจจุบัน

อ่านรายละเอียดข้อมูลที่ใช้และที่เก็บได้ใน [PRIVACY.md](PRIVACY.md) รุ่น 1.3.2 ส่งต่อเฉพาะรหัส วันที่ และสิทธิ์ของโพสต์ให้ตัวทำงาน และรักษาโปรไฟล์ที่เลือกไว้เมื่อเริ่มใหม่จากปฏิทินหลังเชื่อมต่อไม่สำเร็จ

ใช้คำสั่งภายใน Facebook ซึ่งอาจเปลี่ยนโครงสร้างหรือจำกัดความเร็วได้ ส่วนขยายหยุดเมื่อมีข้อผิดพลาด บัญชีเปลี่ยน หรือยืนยันผลไม่ได้ โดยไม่ลองส่งคำสั่งลบเดิมซ้ำอัตโนมัติ

## สำหรับพัฒนา

Node.js 20 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม:

```sh
npm test
```

ทดสอบหน้าต่างและกระบวนการกับโพสต์จำลอง:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

เปิดหน้าเหล่านี้จากเซิร์ฟเวอร์ทดสอบ:

- `/tests/runner.html` — คิว การหยุด ข้อผิดพลาด และงานซ้อน
- `/tests/speed-runner.html` — ความเร็วและการจำค่า
- `/tests/date-runner.html` — วันที่ วันเดียว เดือน และช่วงวันที่
- `/tests/popup-runner.html` — ปฏิทินใต้ไอคอนและการเริ่มงาน

ไฟล์หลัก: `popup.html/js/css` กล่องก่อนเริ่ม, `calendar.js` ปฏิทินและขอบเขตวันที่, `launcher.js` ตรวจโปรไฟล์และนำทาง, `controller.js` หน้าสถานะและคิว, `facebook.js` ตรวจสิทธิ์และสื่อสารกับ Facebook

ข้อมูลใน `tests/fixtures` เป็นข้อมูลจำลอง ไม่มี HAR คุกกี้ โทเคน หรือข้อมูลล็อกอินจริงรวมอยู่ใน repository

## สร้าง ZIP สำหรับแจก

ใช้ Python 3 สร้างจากรายชื่อไฟล์ที่กำหนดไว้เท่านั้น:

```sh
python3 scripts/package.py
```

ได้ ZIP และไฟล์ตรวจสอบ SHA-256 ใน `dist/` มีเฉพาะส่วนขยาย คู่มือ และคำอธิบายความเป็นส่วนตัว ไม่รวมประวัติ Git ชุดทดสอบ หรือไฟล์อื่นในโฟลเดอร์ ผู้รับแตก ZIP แล้วติดตั้งตามขั้นตอนด้านบน รุ่นนี้ติดตั้งแบบ Load unpacked และยังไม่มีระบบอัปเดตอัตโนมัติ
